# 花見の丘 · 日系浪漫花海（Three.js 程序化场景）

**在线地址：https://fengsaoyusama.github.io/flower-sea/**

一片会随风起伏的粉色波斯菊花海：樱花树、白色雏菊、油菜花田、夕阳暖光、富士山、
飘落花瓣、长椅与远山 —— **没有一张贴图、没有一个模型文件**，全部由代码生成。

## 打开方式

直接**双击 `index.html`**（不需要服务器、不需要联网，three.js 已本地内置）。
首次加载会即时生成贴图与几万株花，约 1~3 秒。

## 操作

| 控制 | 说明 |
| --- | --- |
| 自动 | 电影感运镜：沿小路缓慢推近远丘上的樱花树（默认） |
| 漫游 | 自由视角：**拖动鼠标**环视，**WASD** 走动，**Shift** 加速，滚轮推拉 |
| 风 | 切换风力：微风 / 轻风 / 劲风（花海摆幅实时变化） |
| 机位 | 4 个预设：远望 / 花间 / 树下 / 回望 |
| 截图 | 导出当前画面 PNG |
| 全屏 | 全屏观看 |

URL 参数（录屏/截固定机位用）：

```
index.html?cam=0        # 0~3 固定机位
index.html?cam=auto     # 自动运镜（默认）
index.html?ui=0         # 隐藏 UI
index.html?ss=1.5       # 超采样倍率 1~2（画质/性能）
```

## 画面构成

- **花海**：约 1 万株花（粉色波斯菊 / 白雏菊 / 油菜花 / 草），交叉面片 + 实例化渲染，
  顶点着色器注入风摆动画（按世界坐标错相，像真正的风浪）
- **樱花树**：程序化树干/枝条 + 三层蓬松花冠面片（每棵树约 40 片），远景「一本樱」构图
- **环境**：起伏地形、曲线土路、远山与富士山剪影、程序化云层、夕阳暖光、体积光柱
- **氛围粒子**：飘落樱花瓣、近景梦幻光斑、远处薄雾
- **后处理**：自写 GLSL —— Bloom / 伪景深 / ACES 色调映射 / 暖色分级 / 暗角 / 胶片颗粒

## 文件结构

```
index.html            入口 + UI
src/textures.js       程序化贴图（草地、波斯菊、雏菊、油菜花、樱花、云、富士山、土路、木纹…）
src/main.js           地形、花海、樱花树、风摆、粒子、相机、后处理
vendor/three.min.js   three.js r149（本地内置）
tools/                开发期无头 Chrome 截图脚本（非运行必需）
preview/              渲染预览图
```

## 说明

- 这是程序化风格化场景：氛围优先，不追求写实。花是面片贴图（近看有「片感」），
  远景靠雾与构图营造层次。
- 想改成 9:16 竖屏、录成 mp4、换天气（黄昏/雪景/夜樱）或换配色，都可以在 `src/` 里改。
