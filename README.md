# 花見の丘 · 日系浪漫花海（Three.js 程序化场景 · 固定镜头版）

**在线地址：https://fengsaoyusama.github.io/flower-sea/**

**固定镜头**的一幅「日系花海」画面：粉色波斯菊花海、樱花树、富士山、飘落花瓣，
樱花树下还有一对坐着的情侣和小兔子。没有一张贴图、没有一个模型文件，全部由代码生成。

## 亮点

- **固定镜头**：相机不再移动，专心打磨一个画面（背景/前景/构图）
- **昼夜四种时段**：清晨 / 正午 / 黄昏 / 夜樱（光照、天空、雾、云、远山、曝光整体过渡）
- **三种天气**：晴 / 薄雾 / 樱吹雪（雾气浓度、花瓣数量与速度、风力联动）
- **情侣互动**：樱花树下的两人 + 野餐布 + 野餐篮 + 小兔子，女生会周期性靠向男生，
  夜樱时树下灯笼会亮起
- **全程序化**：花海（约 1 万株，顶点着色器风摆）、樱花树（分叉枝干 + 花团）、
  落樱地毯、天空渐变、云、富士山、蝴蝶、萤火虫、花瓣粒子、Bloom/景深/调色

## 打开方式

直接**双击 `index.html`**（无需服务器、无需联网，three.js 已内置）。
首次加载会即时生成贴图与花海，约 1~3 秒。

## 操作

| 控制 | 说明 |
| --- | --- |
| 时段 | 循环切换 清晨 / 正午 / 黄昏 / 夜樱（1.8s 平滑过渡） |
| 天气 | 循环切换 晴 / 薄雾 / 樱吹雪 |
| 风 | 微风 / 轻风 / 劲风（花海摆幅实时变化） |
| 循环 | 开启后每 26s 自动切换下一个时段（适合挂机/录屏） |
| 截图 / 全屏 | 导出 PNG / 全屏观看 |

URL 参数（截固定画面用）：

```
index.html?time=0..3      # 0清晨 1正午 2黄昏 3夜樱
index.html?weather=0..2   # 0晴 1薄雾 2樱吹雪
index.html?ui=0           # 隐藏 UI
index.html?ss=1.5         # 超采样倍率 1~2（画质/性能）
```

## 画面构成

- **花海**：约 1 万株（波斯菊 / 白雏菊 / 油菜花 / 草），实例化渲染 + 顶点着色器风摆
- **樱花树**：分叉枝干 + 沿枝端布置的蓬松花团（每棵约 50 片面片）+ 树下落樱地毯
- **天空**：Shader 渐变穹顶（顶/中/地平线三段色 + 太阳光晕），夜间星星与月亮
- **远山**：三层山脊 + 富士山剪影 + 山脚雾带（随昼夜变色）
- **后处理**：自写 GLSL —— Bloom / 伪景深 / ACES / 暖色分级 / 暗角 / 颗粒

## 文件结构

```
index.html            入口 + UI
src/textures.js       程序化贴图（草地/花/樱/云/远山/野餐布/落樱/蝴蝶/光晕…）
src/main.js           地形、花海、樱花树、情侣、昼夜天气、后处理
vendor/three.min.js   three.js r149（本地内置）
tools/                开发期无头 Chrome 截图脚本（非运行必需）
preview/              渲染预览图（清晨/正午/黄昏/夜樱）
```
